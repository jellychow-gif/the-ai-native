# The AI Native

Weekly signals on how organizations are being rebuilt around AI.

每周五早上 8 点更新。从全球筛选 8–9 条关于 AI 原生组织（AI Native Organization）构建的前沿信号，面向"组织变革推动者"。

## 三大板块

- **Organization** — 认知输入：AI 原生组织如何构建？
- **HR** — 专业输入：HR 各模块如何被 AI 重构？
- **Industry** — 行动输入：全球 HR AI 工具有哪些？哪些值得 dogfood？

## 技术栈

- Python 3.12（抓取与评分流水线）
- SQLite（候选池与发布数据）
- Anthropic API（Claude Haiku 评分 / Sonnet 摘要）
- Next.js + Tailwind CSS（站点）
- Vercel（部署）
- GitHub Actions（每日抓取 + 每周四自动出草稿）

## 更新承诺

A weekly signal layer for leaders rebuilding their organizations around AI.
